# CHEBURCOIN

Личный дашборд по финансовым рынкам: крипта, акции и облигации Московской биржи, биржевые фонды и сводный инвестиционный портфель. Всё в одном месте — курсы, графики, новости и твои реальные активы из Т-Банка, Bybit и крипто-кошельков.

**Демо:** [cheburcoin.ru](https://cheburcoin.ru)

## Что умеет

### 🏠 Главная — дашборд рынка
Быстрый срез рынка на одном экране: ключевая ставка ЦБ, индекс IMOEX, курсы валют и нефть, тепловая карта по составу индекса Мосбиржи.

### 📈 Крипта
- Список монет с ценами в ₽ и $, полоса состояния рынка, индекс страха и жадности.
- Детальная страница монеты: график цены, ключевые метрики и новости по тикеру.
- Блок «В портфеле» — если монета есть в твоих подключённых кошельках.

### 🏛️ Акции MOEX
- Таблица бумаг с торгов (TQBR).
- Страница инструмента: график, дивиденды, диапазон за 52 недели, калькулятор позиции и блок «В портфеле» с реальной прибылью (курсовая + реализованная по проданным лотам + дивиденды за вычетом налога).

### 📃 Облигации
- Таблица ОФЗ, корпоративных и муниципальных облигаций с фильтром по сектору.
- Фильтр «Только надёжные» (по спреду доходности к ключевой ставке).
- Детальная страница: параметры выпуска, калькулятор доходности, график амортизации и купонов.

### 🧺 Фонды
Биржевые фонды (БПИФ/ETF) с категорией актива.

### 💼 Портфель
Сводный портфель из нескольких источников в одном дашборде:
- **Т-Банк** — по своему токену Tinkoff Invest (счета, позиции, прибыль).
- **Bybit** — балансы аккаунта по API-ключу.
- **Крипто-кошельки** — BTC / ETH / SOL по адресу или xpub (read-only, устройство не нужно).

Дашборд показывает KPI, распределение (по типу / сектору / классу активов), таблицу позиций с колонкой прибыли и календарь будущих купонов и выплат.

### 📰 Новости
Общая лента новостей рынка на русском (ForkLog, Incrypted, Investing) с тональностью.

### Прочее
- 🔐 Авторизация через Firebase.
- ⭐ Избранное.
- 🌗 Тёмная и светлая тема.
- 📱 Устанавливается как приложение (PWA).

## Как пользоваться

1. Открой приложение и зарегистрируйся / войди.
2. Смотри рынок в разделах «Крипта», «Акции», «Облигации», «Фонды» — данные подтягиваются автоматически, ключи не нужны.
3. Чтобы увидеть **свой портфель**, зайди в раздел «Портфель» и подключи источники на экране «Источники данных»:
   - **Т-Банк** — вставь токен Tinkoff Invest (лучше read-only).
   - **Bybit** — укажи API-ключ и секрет.
   - **Крипто-кошелёк** — вставь адрес или xpub кошелька (Trezor / Ledger / MetaMask / Phantom).
4. Отмечай интересные монеты в избранное и переключай тему по вкусу.

> Токены и ключи используются только для чтения данных твоего портфеля. Для Т-Банка и Bybit достаточно read-only доступа — не выдавай ключам права на торговлю или вывод средств.

## Для разработчиков

Код открыт, но приложение задумано как задеплоенный сервис, а не как локальная песочница: для полноценного запуска нужны собственный конфиг Firebase, ключи для крипто-провайдеров и прокси-бек `tbank-api` для портфеля Т-Банка (часть внешних API недоступна с локалхоста и работает только через деплой). Структура кода:

```
src/
├── app/          # роуты App Router (страницы и API-роуты)
├── components/   # компоненты по фичам
├── store/        # Zustand-сторы (auth, тема, избранное)
└── utils/        # форматирование, хелперы
apiFn/            # клиенты внешних API
models/           # TypeScript-типы ответов API
configs/          # конфиг Firebase
```
